# WikiQuestion — Ask & Answer Platform

Welcome to our project! **WikiQuestion** (Qistoun) is a Persian (RTL) community Q&A web application built with **Django**, **Python**, and vanilla **HTML, CSS, and JavaScript**. Users can ask questions, browse channels, connect with members, and earn reputation points.

## 🚀 Features

* **RTL Persian Interface:** Built from the ground up with right-to-left layout support and custom **Vazir** typography.
* **Community Navigation:** Quick access to top-level pages (About, Channels, Feedback, Rules) and a persistent sidebar for core actions (Home, Questions, Networking, Messages, Members, Tags, Scoring, Help).
* **Custom Dark UI:** Clean, dark-themed interface styled with raw CSS variables and hover transitions.

## 🛠️ Tech Stack

* **Backend:** Python, Django Framework
* **Frontend:** HTML 5, CSS 3, Vanilla JavaScript
